# K 线回测未来函数与时点偏差审计

> 审计日期：2026-07-11  
> 审计分支：`codex/kline-data-source-selector`  
> 结论：当前策略指标、信号与成交引擎未发现未来函数；默认前复权数据仍存在非严格 point-in-time 风险，首期按需求文档接受该近似。

## 1. 审计口径

未来函数是指在交易日 `T` 产生信号或成交时，使用了 `T` 时点尚不可知的价格、指标或事件。本次审计同时区分：

- **代码级未来函数**：负向 `shift`、居中滚动、未延迟的右侧确认、当日收盘信号按当日开盘成交等。
- **数据时点偏差**：代码未直接读取未来行情，但历史数据可能被日后信息重算。
- **展示层回看偏差**：图表事后绘制范围与指标当时的可见范围不一致，但不参与交易计算。

## 2. 指标逐项结论

| 指标或流程 | 结论 | 时点口径 |
|---|---|---|
| MA5/MA20 | 通过 | 滚动均值只累计当日及之前的收盘价。 |
| 金叉/死叉 | 通过 | 只比较 `T-1` 与 `T` 的短长均线。 |
| 拐点 | 通过（右侧确认） | 默认等待 3 根右侧 K 线，并通过 `confirmed_index` 延迟暴露；不在拐点原日生成信号。 |
| 斐波上涨波段 | 通过 | 只从当日已可见的确认拐点中选择。 |
| 斐波回撤位及触及 | 通过 | 水平位来自已确认波段，触及只使用当日 high/low。 |
| 斐波反弹确认 | 通过 | 只使用当日开收盘和上一日收盘。 |
| 斐波失效 | 通过 | 当日收盘与进场时绑定的波段快照比较。 |
| 趋势线 | 通过 | 两个锚点必须已确认；第三触点从第二锚点确认日之后统计。 |
| 趋势线跌破 | 通过 | 当日收盘判定，下一交易日开盘执行。 |
| 策略 A/B/C/D | 通过 | 全部消费当日指标快照，无额外未来行情引用。 |
| 止损/止盈 | 通过 | 持仓当日的 high/low 触发风险退出单，下一交易日开盘成交。 |
| 盈亏比、胜率、回撤、夏普等 | 通过 | 只在回测结果上事后统计，不反馈到信号。 |

## 3. 成交时序

策略在 `T` 日完整 K 线收盘后评估，生成 `planned_index = T + 1` 的挂单，并于下一可交易日开盘执行。停牌、涨跌停和挂单顺延不会将之后的价格回填到原信号日。同一根 K 线同时触发止损和止盈时优先止损，属于保守假设。

## 4. 动态与静态验证

- 静态扫描未发现 `shift(-1)`、居中滚动、`LEAD`、负向移位等典型未来引用。
- 右侧 K 线读取只出现在拐点确认中，并受 `confirmed_index <= current_index` 的可见性门控。
- 前缀不变性测试：对同一组 40 根合成 K 线分别输入前 1 至前 40 根，每个截止日的指标快照均与输入完整序列后对应历史日快照一致，结果 `40/40 PASS`。
- 前端图层工具测试覆盖有效趋势线分段和斐波最新合格波段的实际可见起止日。

## 5. 已知时点风险

### 5.1 前复权

默认股票回测使用 `qfq`。数据供应商可能在日后分红、送转或除权除息后重算过去的前复权价格，因此它不是严格的 point-in-time 数据。该风险会影响绝对价格、整手数量、费用和止盈止损位。

首期依据需求文档接受该近似，并保存数据源、AkShare 版本、复权方式、获取时间和数据哈希以保证单次 run 可追溯。若未来要求严格时点回测，应改为原始不复权价格加历史公司行动事件，在模拟时逐日调整持仓和资金。

### 5.2 斐波图层

审计时发现前端曾将最后一组斐波水平线延伸到图表期末，即使该波段后续已不再有效。该问题只影响事后可视化，不影响后端信号和成交。收尾修复将最新合格波段的水平线终点截在其最后可见日，并增加回归测试。

## 6. 后续指标的强制验收规则

新指标接入策略前必须同时满足：

1. 公式中只能读取当日及之前的行情。
2. 右侧确认型指标必须显式保存确认日，不得在原始锚点日产生信号。
3. 收盘后信号最早只能在下一可交易日成交。
4. 增加前缀不变性测试，追加未来 K 线不得改变已完成日的指标快照。
5. 明确窗口不足、分母为零、停牌、涨跌停和数据缺失时的行为。
